# Demo Workspace

## What This Workspace Is For
Everything needed for submission: the 90-second demo script, presentation, video plan, and the submission checklist with pre-filled answers.

## Process
1. Finalize the demo script after build sprints 1–3 are solid.
2. Record a backup demo (screen recording) before the final sprint ends.
3. Fill submission fields using the templates here.
4. Cross-check every link in an incognito window before 17:30.

## Files In Here
- `demo_script.md` — The 90-second video script, beat by beat.
- `submission_checklist.md` — Every field the Google Form asks, pre-drafted.
- `presentation_plan.md` — Slides or visual plan for the submission link.

## What Good Output Looks Like
A teammate can read `demo_script.md` and narrate the demo cold, hitting every rubric criterion in 90 seconds. The `submission_checklist.md` is copy-pasteable into the Google Form.

## Constraints
- Never claim features that don't work. Label mocked/simulated parts honestly.
- Demo must show a LIVE triggered failure, not a screenshot.
- Backup recording exists before 16:00 Tunis time.
