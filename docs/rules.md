# Hackathon Rules — Distilled

Source: [hackathon.gomycode.com/onboarding](https://hackathon.gomycode.com/onboarding)

## Event
- **Date:** 27 September 2026
- **Nigeria times (same as Tunis, UTC+1):**
  - 08:30 Check-in → 09:00 Opening → 11:15–17:00 Build sprints → 17:30 Submission deadline
  - 17:45–19:15 Country judging → 19:15–19:45 Live demos (top 3 Nigeria) → 20:00 Close

## Submission Requirements (Google Form, once, by 17:30)
1. **Same team name + lead email** as Final Team Confirmation
2. **Project title + summary** ≤ 150 words (problem, solution, features, tech, next step)
3. **Working prototype** — functional, core feature easy for jury to see
4. **Source code URL** — accessible to reviewers
5. **Presentation URL** — accessible to reviewers
6. **90-second demo video** — problem → product → proof → what's next
7. **Prize selection** — one primary + checkboxes for partner awards
8. **Evidence of award fit** — 2–3 sentences per selected award
9. **AI/tool disclosure** — all models, APIs, datasets, what's real vs mocked, Brev usage (if any)
10. **All links tested** in incognito/signed-out window before submitting

## Key Constraints
- Judging is **tool-neutral** — no bonus for Brev usage, no penalty for not using it
- Solo participants cannot request Brev credits
- Label mock data honestly; never include API keys in submissions
- Only top 3 per country give live demos; everyone else is evaluated from submitted materials
- One primary prize dropdown + partner award checkboxes
